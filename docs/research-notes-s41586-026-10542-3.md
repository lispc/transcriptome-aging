## 1. Paper Overview (Bilingual)

### English Summary

This study integrates **>11,000 transcriptomes** from **>25 tissues** across **4 mammals** (mouse, rat, macaque, human) to develop transcriptomic clocks (tAge) that predict not just chronological age, but **expected mortality**—a proxy for molecular health and biological damage accumulation.

**Core achievements:**
- Multi-species, multi-tissue clocks of chronological age and expected mortality.
- Mortality clocks outperform dedicated lifespan clocks in distinguishing lifespan-extending vs. shortening interventions.
- Identified conserved ageing signatures: **CDKN1A, LGALS3, GPNMB** (up with age); **Nrep, COL1A1, COL3A1** (down with age).
- Decomposed ageing into **28 co-expression modules** (inflammation, interferon, mitochondria, chromatin, ECM, etc.) with module-specific clocks.
- Validated in vitro (replicative senescence, metabolic stress, γ-irradiation, reprogramming) and in vivo (chronic diseases, heterochronic parabiosis, embryogenesis).
- Human relevance: FHS blood data predicts time to death; UK Biobank plasma validates **GPNMB, CDKN1A, LGALS3** protein associations with mortality and disease.

**Key insight:** Ageing is modular. Different interventions target different modules:
- Chronic diseases accelerate inflammatory module ageing.
- Caloric restriction rejuvenates metabolic/mitochondrial modules.
- Klotho deficiency accelerates metabolic modules without strong inflammatory activation.

## 2. Models & Algorithms Deep Dive

### What it is NOT

- **Not** a large language model or Transformer.
- **Not** a deep neural network (not the main model).
- **Not** a decision tree or random forest (tested but rejected).

### What it IS

The primary models are **Elastic Net** (sparse linear regression with L1+L2 regularization) and **Bayesian Ridge** (linear regression with probabilistic uncertainty estimates).

**Model structure:**
```
tAge = β₀ + β₁·gene₁ + β₂·gene₂ + ... + βₙ·geneₙ
```

| Component | Details |
|---|---|
| **Input** | ~18,000 gene expression values (scaled or YuGene-normalized) |
| **Preprocessing** | **Relative expression**: subtract median of age/sex/tissue-matched controls to eliminate batch effects |
| **Model** | Elastic Net (scikit-learn) — automatically drives most gene coefficients to zero, keeping only ~100–2,000 genes |
| **Output** | Age deviation (months) or mortality deviation (log₁₀ hazard ratio) |

**Why Elastic Net won over complex models:**
1. **Sparsity**: Automatic feature selection.
2. **Interpretability**: Each gene has one coefficient. Positive = pro-ageing/pro-mortality; negative = protective.
3. **Stability**: Outperformed SVM, LightGBM, Random Forest, KNN in cross-dataset generalization (LODO/LOTO).
4. **Performance**: Test set R² ≈ 0.92, Pearson r ≈ 0.95–0.96 — already comparable to epigenetic clocks.

**Module-specific clocks** are the same Elastic Net architecture, just trained on subsets of genes belonging to each WGCNA module.

## 4. ARCHS4 MoE vs This Paper

### ARCHS4 MoE Preprint (medRxiv, June 2025)

| Attribute | ARCHS4 MoE | This Nature Paper |
|---|---|---|
| **Samples** | 56,876 humans (ARCHS4 database) | 11,165 (4 species, 25+ tissues) |
| **Model** | Mixture-of-Experts (3 experts: young/middle/old) | Elastic Net / Bayesian Ridge |
| **Target** | **Chronological age ONLY** | Age + Mortality + Module decomposition |
| **Performance** | R² = 0.812, MAE = 7.58 years | R² = 0.92, MAE ≈ 0.26 (relative) |
| **Species** | Human only | Mouse, rat, macaque, human |
| **Tissues** | Mostly blood | 25+ tissues |
| **Interventions** | ❌ None | ✅ 79 interventions validated |
| **Mechanism** | ❌ Black box | ✅ Gene-level + module-level interpretable |
| **Clinical validation** | Internal CV only | FHS prospective death prediction + UK Biobank protein validation |
| **Open source** | ⚠️ No code/model seen in preprint | ✅ Yes (Zenodo + GitHub) |

### Key Insight

ARCHS4 MoE is **NOT** a superior replacement. It is a **larger but narrower** model:
- ARCHS4 MoE = higher-resolution **age camera** (bigger data, better at guessing birth year).
- Nature paper = **medical diagnostic system** (predicts death, decomposes into organ-level module ageing, validates interventions).

> **Paper finding**: Age accuracy and mortality prediction are largely UNCOUPLED. A model can be great at guessing age but useless at predicting death (and vice versa).

**How to use ARCHS4 MoE for cross-validation:**
- If accessible: run the same drug perturbation signatures through both models. If tAge mortality clock and ARCHS4 MoE agree on direction (rejuvenating vs ageing), confidence increases.
- If not accessible: train your own age-stratified Elastic Net on ARCHS4 as a baseline.

## 5. Direction C: Drug Module Fingerprinting & Combination Optimization

### Core Concept

Build a **"module fingerprint"** for each drug: a vector showing how the drug affects each of the 23 ageing modules.

```
Drug X Module Fingerprint = [
  inflammation:    -1.2  (rejuvenated)
  mitochondria:    -2.5  (strongly rejuvenated)
  interferon:      +0.3  (slightly accelerated — side effect)
  cell_cycle:      +0.1  (neutral)
  ...
]
```

Then use this to:
1. **Rank single drugs** by their module-specific rejuvenation effects.
2. **Find complementary drug pairs** whose module vectors cancel out side effects.
3. **Screen novel compounds** by matching their transcriptomic signature to known rejuvenation patterns.

### The Pipeline Architecture

```
┌─────────────────────────────────────────────────────────────┐
│  INPUT: Drug perturbation transcriptome (LINCS L1000)       │
│         or bulk RNA-seq (GEO)                               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  PREPROCESS: Relative expression (drug vs control)          │
│              Same centring strategy as tAge training        │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  MODEL LAYER:                                               │
│    - Composite mortality clock → overall tAge Δ             │
│    - 23 module-specific clocks → module tAge Δ vector       │
│    - ARCHS4 MoE (if available) → scalar age Δ               │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  OUTPUT: Drug Module Fingerprint                            │
│          + Cross-model consistency score                    │
└─────────────────────────────────────────────────────────────┘
```

### Why This Hasn't Been Done

- scGPT/Geneformer predict **perturbation expression** but stop there. They don't map to ageing modules.
- tAge clocks measure **ageing/mortality** but were trained on natural ageing + genetic interventions, not systematic drug perturbations.
- **Nobody has connected the two**: perturbation prediction → module-level ageing quantification.

## 6. Data Quality: Problems and Solutions

### The Core Problem

"Virtual cell" approaches need high-quality **paired perturbation-ageing data**. Such data is scarce because:
- Most Perturb-seq/sci-Plex data uses cancer cell lines, not physiologically ageing primary cells.
- Drug perturbation studies rarely include ageing-related phenotypes or survival data.
- Bulk RNA-seq drug studies exist but are fragmented across GEO.

### The Solution: LINCS L1000

**LINCS L1000** (Broad Institute) is the best immediately available resource:

| Property | Detail |
|---|---|
| **Scale** | ~1 million signatures, ~20,000 compounds, 100+ cell lines |
| **Technology** | Measures 978 landmark genes (+ inferred full transcriptome) |
| **Data level** | Level 5: moderated Z-scores, batch-corrected, reproducibility-filtered |
| **Access** | [iLINCS](https://www.ilincs.org/), GEO (GSE92742, GSE70138), REST API |
| **Cost** | FREE |

**Why LINCS is sufficient for module clocks:**
- The 978 landmark genes are selected to be maximally informative about the full transcriptome.
- Module clocks' core genes (inflammation hubs, mitochondrial genes) are well-represented in the landmark set.
- The inferred full-transcriptome matrix (Level 3) can be used if needed.

### Supplementary Data Sources

| Source | What | How to use |
|---|---|---|
| **ITP data from this paper** | Liver RNA-seq from mice treated with rapamycin, acarbose, 17α-estradiol, etc. | Direct validation — already has mortality tAge validated |
| **GEO drug+ageing studies** | Search: `metformin aging RNA-seq`, `rapamycin longevity mouse` | Independent validation set |
| **ARCHS4** | 57K uniformly processed human RNA-seq | Meta-analysis baseline; can train alternative age models |
| **sci-Plex / Perturb-seq** | Single-cell drug screens | For single-cell-resolution module ageing (future phase) |

### Technical Solutions to Data Quality Issues

| Issue | Solution |
|---|---|
| **LINCS only has 978 measured genes** | Use inferred gene matrix; or run module clocks on landmark gene subset only (sufficient for core modules). |
| **Cell lines ≠ primary cells** | Use relative expression (drug vs DMSO within same cell line) to cancel baseline. Prioritize physiologically relevant lines (HepG2 for liver, MCF7 for breast, etc.). |
| **Concentration/time heterogeneity** | Meta-analyze across concentrations/times: take median or consensus signature per drug. Filter for reproducible signatures only. |
| **No direct ageing readout in LINCS** | This is BY DESIGN — we ADD the ageing readout via tAge module clocks. LINCS tells us "what changed"; tAge tells us "what does that mean for ageing". |
| **Species mismatch (tAge trained on rodents)** | Use the **multi-species universal clocks** from the paper. They already handle human/mouse/rat/macaque ortholog mapping internally. |

## 7. Single-Drug Sanity Checks

Before building complex combination models, validate the pipeline on drugs with **well-established mechanisms and known ageing effects**.

### Metformin

| Known Mechanism | Expected Module Effect | Expected tAge Direction |
|---|---|---|
| AMPK activation → ↑ mitochondrial biogenesis, ↑ fatty acid oxidation | Mitochondrial translation / OxPhos module | ↓ (rejuvenated) |
| mTORC1 inhibition → ↑ autophagy, ↓ protein synthesis | Protein processing / UPR / mTOR sig module | ↓ (rejuvenated) |
| NF-κB inhibition → ↓ inflammation, ↓ SASP | Innate immunity / inflammation module | ↓ (rejuvenated) |
| Gut microbiome modulation | AA/xenobiotic metabolism module | Variable |

**Data availability**: ✅ **Abundant in LINCS L1000**.

**Pass criteria**: Metformin should show **metabolic and mitochondrial module rejuvenation** as the strongest signals. If it instead predicts accelerated ageing, the pipeline has a bug.

### Rapamycin (Sirolimus)

| Known Mechanism | Expected Module Effect | Expected tAge Direction |
|---|---|---|
| Potent mTORC1 inhibition → ↑ autophagy, ↓ protein synthesis | Protein processing / mTOR module | ↓↓↓ (strongly rejuvenated) |
| Immunosuppression | Adaptive immunity / T-cell module | ↑ (accelerated — known side effect) |
| Metabolic reprogramming | Fatty acid / cholesterol metabolism | ↓ (rejuvenated) |

**Data availability**: ✅ **In LINCS L1000** + ✅ **Directly in this paper's ITP data**.

**Pass criteria**: The paper **already validated** that rapamycin reduces mortality tAge (Fig 1p). Our pipeline should **reproduce this**. Bonus: if module decomposition shows **immune module acceleration** alongside metabolic rejuvenation, it demonstrates the module clocks are capturing side effects.

### NMN / Nicotinamide Riboside (NAD+ Precursors)

| Known Mechanism | Expected Module Effect | Expected tAge Direction |
|---|---|---|
| NAD+ ↑ → Sirtuin activation → ↑ mitochondrial function | OxPhos / mitochondrial translation module | ↓ (rejuvenated) |
| ↑ DNA repair capacity | Cell cycle / DNA replication module | ↓ (rejuvenated) |
| Improved energy metabolism | Fatty acid metabolism / haem metabolism | ↓ (rejuvenated) |

**Data availability**: ⚠️ **May not be in LINCS L1000** (dietary supplement, not typical drug). But **GEO has independent studies** (e.g. NMN/NR treatment in mouse liver RNA-seq).

**Pass criteria**: If data found, expect **mitochondrial module** to be the strongest rejuvenation signal.

### Negative Controls (Should Predict Pro-Ageing)

| Drug | Known Effect | Expected Module Effect |
|---|---|---|
| **Doxorubicin** | Chemotherapy, DNA damage, induces senescence | DNA damage, apoptosis, inflammation modules ↑ |
| **Dexamethasone** | Glucocorticoid, known to accelerate ageing | Metabolic dysfunction, immune suppression modules ↑ |
| **LPS** (lipopolysaccharide) | Acute inflammation | Innate immunity, interferon modules ↑ |

**Pass criteria**: These should consistently show **increased mortality tAge** across multiple modules. The paper already validated LPS (Fig 3d, 3e).

## 8. Phase 0-3 Roadmap

### Phase 0: Sanity Check (4–6 weeks)

**Goal**: Prove the pipeline works on known drugs.

**Deliverables**:
1. Download LINCS L1000 Level 5 data (GSE92742 + GSE70138).
2. Extract signatures for: Metformin, Rapamycin, Everolimus, Doxorubicin, Dexamethasone.
3. Download tAge models from Zenodo.
4. Run composite + module clocks on each drug signature.
5. Produce a "Module Fingerprint" table for each drug.
6. **Pass/Fail**: Compare predicted module effects against known biology (Section 7).

**If Phase 0 fails**: Debug preprocessing (relative expression centring, species ortholog mapping, batch correction). Check if LINCS inferred matrix is needed instead of landmark-only.

### Phase 1: Drug Module Fingerprint Library (6–8 weeks)

**Goal**: Build a comprehensive library of module fingerprints for ~100 drugs.

**Steps**:
1. Expand drug list to include:
   - Known geroprotectors (resveratrol, spermidine, acarbose, canagliflozin, etc.)
   - Known progerics (chemotherapy, radiation, high-dose glucocorticoids)
   - Common chronic disease drugs (statins, ACE inhibitors, metformin, NSAIDs)
2. For each drug: aggregate signatures across cell lines and concentrations (meta-analysis).
3. Compute robust module fingerprint = median(module tAge Δ) across contexts.
4. Visualize: UMAP of drugs colored by module effect clusters.

### Phase 2: Combination Optimization (8–12 weeks)

**Goal**: Find module-complementary drug pairs.

**Method**:
```
Combination Score = Σ(target_module_rejuvenation) - λ·Σ(side_effect_module_acceleration)
```

1. Define "target modules" (e.g. inflammation + mitochondria) and "avoid modules" (e.g. cell cycle disruption).
2. Search pairwise drug combinations in the 100-drug library.
3. Rank by Pareto optimality: best rejuvenation with least side-effect cost.
4. Cross-check top hits against literature: are there published synergy studies?

### Phase 3: Experimental Validation (6–12 months)

**Goal**: Validate predictions in independent systems.

**Options**:
- **In vitro**: Primary human cells + predicted drug combinations → RNA-seq → tAge module clocks.
- **In vivo**: Use ITP-style mouse cohorts or collaborate with Gladyshev lab.
- **Human data**: Query UK Biobank / FHS for individuals on polypharmacy regimens matching predicted combinations. Test if their blood transcriptomes show module-level rejuvenation.

## 9. Risks & Fallback Plans

| Risk | Impact | Fallback |
|---|---|---|
| **LINCS 978 genes insufficient for module clocks** | Module clocks fail or produce noise | Use LINCS inferred full-transcriptome matrix (Level 3); or restrict module clocks to landmark gene subsets only. |
| **tAge models are rodent-centric, LINCS is human** | Species bias in predictions | Use the paper's **multi-species universal clocks** (trained on mouse+rat+macaque+human). These already include ortholog mapping. |
| **LINCS treatment times too short (24h) for ageing** | Acute drug response ≠ chronic ageing effect | Supplement with chronic-treatment GEO datasets (e.g. metformin 8-week mouse liver). Use LINCS for mechanism, GEO for chronic validation. |
| **ARCHS4 MoE unavailable** | Missing cross-validation baseline | Train your own age-stratified Elastic Net on ARCHS4 (57K samples publicly available). Or skip — use paper's own intervention data as the primary validation. |
| **Drug signatures inconsistent across cell lines** | Noisy module fingerprints | Require concordance across ≥3 cell lines. Discard drugs with conflicting directions. Use reproducibility metrics from LINCS Level 5. |
| **Module clocks pick up cell-line-specific artefacts** | False module ageing signals | Always use **relative expression** (drug vs control within same cell line). Never compare absolute expression across cell lines. |
| **Negative controls don't show pro-ageing effects** | Pipeline fundamentally flawed | If Doxorubicin/Dexamethasone don't increase tAge, check that the model isn't inverted. Verify preprocessing pipeline against paper's tAge R package. |
